# Книги из ЭБС Университетская Библиотека Он-Лайн 

Этот плагин предназначен для добавления в курс публикаций из ЭБС Университетская библиотека ОнЛайн.
При переходе к публикациям авторизация в ЭБС не требуется и происходит автоматически.


Системные требования
--------------------
- Moodle 3.5.3 (сборка 2018051703) и выше: требуется Privacy API со списками пользователей.
- Блок block_biblioclub_ru v0.0.7 (версия 2026101200) и выше.
- Проверено на Moodle 5.2.2 и PHP 8.4.

Установка
---------
Установите плагин используя административную панель moodle.

Совместимость с витриной ЭБС от 14.09.2026
------------------------------------------

Начиная с редизайна ЭБС серверная сессия API использует cookies `uinfo`/`u_tm`,
fingerprint в заголовке `X-Sign` и постоянный User-Agent вместо `PHPSESSID`.
Версия плагина от 14.09.2026 поддерживает этот контракт и продолжает обращаться
к API `https://biblioclub.ru/services/`.

Настройки Moodle не изменились: модуль использует домен организации и секретный
ключ из блока `block_biblioclub_ru`. После обновления обязательно запустите
стандартное обновление базы Moodle через веб-интерфейс администратора или CLI:

```bash
php admin/cli/upgrade.php --non-interactive
```

Персональные данные / Privacy API
--------------------------------

Модуль не хранит пользовательскую историю чтения в собственной таблице Moodle.
Для внешней авторизации ЭБС получает идентификатор и логин Moodle, имя, фамилию,
необязательное отчество, домен организации, время и тип учётной записи. Логин
может быть адресом электронной почты. При работе API передаются внешние cookies,
fingerprint сессии, постоянный User-Agent, идентификатор пользователя ЭБС,
поисковые запросы, коды книг и диапазоны страниц. Cookies временно кешируются
в сессии Moodle, а не в таблице модуля.

В v1.10 эта передача описана в Privacy API. Локальные privacy-запросы не удаляют
книги из курса и не экспортируют/удаляют данные внешнего сервиса. Для запроса
данных или удаления учётной записи на biblioclub.ru нужно обратиться в ЭБС.

Повторная подача в Moodle Plugins Directory
-------------------------------------------

v1.10 исправляет замечания модератора #2–#5: HTTP-запросы используют Moodle `curl`
(с настройками прокси и проверками URL), Privacy API описывает внешние данные,
обработчик запасного перехода вынесен в `locallib.php`, API-класс использует
namespace `mod_biblioclubrubook` и автозагрузку Moodle.

Также исправлена кнопка выбора книги на Moodle 5.2: окно создаётся через
актуальный Modal API; старый `core/modal_factory` подгружается только на старых
версиях Moodle, где он нужен. Обновлены поставляемые JavaScript-бандлы.

См. [проверки и инструкцию для модератора](docs/moodle-review.md).
Замечание [#1](https://github.com/sshaitan/moodle-mod_biblioclubrubook/issues/1)
остаётся условием модерации: сначала должен быть одобрен зависимый блок.
Подавать блок и модуль нужно вместе, явно указав зависимость. Автоматическая
подача в каталог по тегу отключена; публикация выполняется владельцем отдельно.
